# Observatório Saúde

Segunda linha de monitoramento no mesmo GitHub Pages, com identidade visual e dados independentes.

- Página: `/observatorio-2030/saude/`
- Estilo: CSS principal compartilhado com sobreposição `saude/style.css`
- Dados: `saude/data/topics.json` e `saude/data/events.json`
- Eventos: campos `id`, `title`, `summary`, `published_at`, `stage`, `limitations` e `source` (com `url` e `name`).
- Links individuais: `#marco=<id>`
- O monitoramento agendado IMORTAIS 2500 existente não é alterado. Esta interface não importa automaticamente resultados da tarefa.
- Notificações: ainda não há inscrições separadas por observatório no backend Web Push; a página Saúde não oferece assinatura até essa segmentação ser implementada.
- Eventos não foram inventados nem importados sem avaliação.
